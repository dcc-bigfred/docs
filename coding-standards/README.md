# Coding standards

Developer-facing conventions for the BigFred ecosystem. This material is **not**
part of the [published user documentation](https://dcc-bigfred.github.io/docs/) —
it lives outside `content/` and is not built by MkDocs.

Use it in code review, when onboarding contributors, and when deciding where a
new package or abstraction belongs.
